ฟีเจอร์ที่นำเสนอ

01

จัดการโต๊ะและออเดอร์

พนักงานเลือกโต๊ะ เพิ่มเมนู แก้จำนวน ย้ายโต๊ะ และคิดเงินได้ใน flow เดียว

02

ครัวแยก station

ออเดอร์แยกตามเตาต้ม เตาย่าง เครื่องดื่ม และครัวทั่วไป เพื่อให้ทำงานเหมือนร้านจริง

03

QR Order รายโต๊ะ

ลูกค้าสแกน QR ของโต๊ะตัวเอง เลือกเมนู และส่งออเดอร์เข้าเครื่อง POS ได้

แนวทางการทำงานของระบบ

หน้าร้าน

เปิดโต๊ะ รับออเดอร์ ตรวจสถานะอาหาร และชำระเงิน

ครัว

ดูเฉพาะรายการที่เกี่ยวกับ station ของตัวเอง แล้วเปลี่ยนสถานะเมื่อทำเสร็จ

ผู้จัดการ

เพิ่มเมนู ตั้งราคา ดูรายงานยอดขาย และจัดการสิทธิ์พนักงาน

เทคโนโลยีที่ใช้

  • React Frontend
  • Node.js Backend
  • Express API
  • MongoDB Database
  • Docker Deploy
  • Role Permission
  • Kitchen Station
  • QR Ordering
